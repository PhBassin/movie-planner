# Deployment Guides

Movie Planner supports **local development only**. Production/VPS deployment,
container-registry publication, and the bundled monitoring stack were removed
in issue #3 (PR 4).

- [Docker Setup](./docker.md) — `compose.yaml` and `compose.infra.yaml`, local builds, volumes
- [Networking](./networking.md) — local ports, LAN access, CORS
